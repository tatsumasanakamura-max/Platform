# アクセシビリティ

## 目標

WCAG 2.2 AAを設計目標とする。自動テスト合格だけで適合を宣言しない。React Aria Componentsを利用しても、名称、説明、エラー文、フォーカス順、視覚コントラストは本プロジェクトが確認する。

## 実装基準

- 主要フローをキーボードだけで完了できる。
- `:focus-visible`を3pxの高コントラスト輪郭で表示する。
- DOM順と視覚順を一致させ、フォーカスを意図せず移動しない。
- セクション検証エラー時はErrorSummaryへフォーカスする。
- ErrorSummaryの各リンクから対象入力へフォーカスできる。
- Label、description、error、required、invalidをプログラムで関連付ける。
- 状態は色だけで示さず、記号、文面、枠線を併用する。
- 本文16px以上、タップ領域44×44px以上とする。
- 200%拡大、320px幅、長い日本語文言で主要操作を維持する。
- `prefers-reduced-motion: reduce`で不要な遷移を無効にする。
- 処理中はボタンを無効化し、ライブ領域へ状態をテキスト表示する。
