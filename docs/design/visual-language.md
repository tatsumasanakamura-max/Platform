# ビジュアル言語

## Calm Trust

温かみのあるオフホワイト、深いネイビー、落ち着いた操作ブルーを基調にする。グラデーション、ガラス表現、過剰な影・装飾・アニメーションは使用しない。銀行差分は将来トークン差し替えで吸収できるが、PoC-1でテーマ切替機能は作らない。

## トークン

正は[`src/styles/tokens.css`](../../src/styles/tokens.css)とする。

| 分類         | 基準                                              |
| ------------ | ------------------------------------------------- |
| 背景         | `#f7f8fa`                                         |
| ブランド     | `#102a43`                                         |
| 操作         | `#1769aa`、hover時`#12598f`                       |
| 本文         | `#17212b`                                         |
| エラー       | `#a61b12`と薄い赤背景。色に加えて記号と文面を使う |
| 成功         | `#18794e`と薄い緑背景                             |
| 余白         | 4px基準、主要間隔は16／20／24／32px               |
| 角丸         | 入力10px、カード14px                              |
| 影           | カードに7%不透明度の弱い影だけ                    |
| コントロール | 高さ54px、タップ領域44×44px以上                   |
| 本文         | 16px、行間1.65                                    |
| タイトル     | 24〜28px                                          |
| コンテンツ幅 | 最大640px                                         |
| モーション   | 140ms。`prefers-reduced-motion`時は実質無効       |

## レスポンシブ

- 320px以上で横スクロールを発生させない。
- モバイル左右余白は20px、700px以上は32pxとする。
- 390×844前後を主な実機相当基準にする。
- 200%拡大時も1カラムを保ち、主要操作を利用可能にする。
- 画面下部に`safe-area-inset-bottom`を加味した余白を持たせる。

## フォント

外部Webフォントを要求せず、OS標準の日本語フォントスタックを使う。入力中の通信、描画遅延、プライバシー依存を増やさない。
