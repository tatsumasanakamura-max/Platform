# Studioユーザーガイド

1. `/studio`を開き、組込定義または`JSON読込`でBaselineを用意する。
2. 左の項目を選び、上・下・複製・削除・セクション移動を行う。
3. 右の基本／文言／検証／条件タブで属性を編集する。
4. 中央Previewへ即時反映された通常状態を入力操作で確認する。
5. テスト値を入れ、エラーPreviewで項目近傍とErrorSummaryを確認する。
6. `検証`のエラーを0件にし、警告と未解決事項を確認する。
7. `保存`は仮想商品の定義だけをlocalStorageへ保存する。
8. JSON、差分、要件書を出力し、レビュー・Codex・テストへ渡す。

主要操作はTabで移動でき、左の項目は上下矢印でも移動できる。削除ダイアログはEscapeで閉じられる。狭い画面は上部の3タブでペインを切り替える。実在人物の情報や実銀行仕様を入力しない。
