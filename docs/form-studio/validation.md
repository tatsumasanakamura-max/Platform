# Studio検証

## エラー

Schema違反、重複ID、参照切れ、遷移不正、未知の項目形式・validator、グループ参照切れ、シナリオ参照切れ、自分自身への条件依存をエラーとする。エラー中はlocalStorage保存と全エクスポートを無効にする。不正ImportはBaselineとDraftを変更しない。

## 警告

長いラベル、ヘルプなし、ラベルと同じplaceholder、選択肢1件、後続セクション参照、版未更新、Studio非対応の複合条件を警告とする。警告は出力を妨げず、`open-questions.md`へ派生できる。

検証一覧の項目付き指摘を押すと対象設定へ移動する。自動検査は完全な業務妥当性を保証しないため、警告と未解決事項を人間が確認する。
