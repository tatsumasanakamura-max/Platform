# フォーム要件定義スタジオ

## 目的

フォーム要件定義スタジオ（`FormStudio`）は、実際のスマートフォン表示を見ながら仮想商品の要件を編集し、合意結果を実行可能な`FormDefinition`としてCodex、自動テスト、申込画面、派生文書へ渡すPoC-1B機能である。フォームごとのReactコードは生成せず、申込画面とStudio Previewが同じ`RuntimeField`、ルールエンジン、名前付きバリデーターを使う。

## 画面

- 画面構成: セクション、グループ、項目、順序、必須、依存、指摘を表示する。
- スマホプレビュー: 約390pxで通常、エラー、最大2件のシナリオを動作確認する。
- 項目設定: 基本、文言、検証、条件、テストの5タブで編集する。
- 900px以下: `構成 / プレビュー / 設定`のタブへ切り替える。

入口は`/studio`である。Firebase、認証、共同編集、公開管理、任意コード、任意正規表現、ドラッグ＆ドロップは含まない。

## 正となる情報

`FormDefinition JSON`が正であり、Markdownとchange manifestは派生成果物である。属性契約は[フォーム定義](../07_form_definition.md)、編集状態は[編集モデル](editing-model.md)、出力は[出力形式](export-format.md)、検証は[検証](validation.md)を正とする。
